SHADOW VEIL
===========

Thank you for playing.

Starting the game
  Windows : double-click ShadowVeil.exe
  Linux   : run ./shadow-veil (Wayland or X11). To add it to your app menu, copy
            dev.shadowveil.game.desktop to ~/.local/share/applications and edit Exec= to point here.

Controls
  A controller is recommended (PlayStation, Xbox and most others work out of the box).
  Keyboard: WASD / arrows move, Space jump, J (or left mouse) attack, K (or right mouse) deflect,
  L / Shift dash, F grapple, R shuriken, Q art, C heal, E interact, Tab gear, Esc pause.
  Every binding is shown on screen when it matters.

Saves and settings
  Windows : %APPDATA%\XSO\Shadow Veil\
  Linux   : ~/.local/share/shadow-veil/
  A log (shadow-veil.log) is written there too; please attach it to any bug report.

System requirements
  64-bit Windows 10/11 or a 64-bit Linux desktop, and a GPU with OpenGL 3.3.

Fonts: Noto Serif and Noto Serif CJK, SIL Open Font License 1.1 (assets/fonts/OFL.txt).
Libraries: SDL3 (zlib license), FreeType (FreeType License), zlib (zlib license).
